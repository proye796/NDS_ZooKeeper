- BUG-021 — 용어사전에서 L/R 페이지 이동 시 항목을 건너뛰는 문제: 한 화면에 7개가 표시되는데 8개씩 이동하던 처리를 7개씩 이동하도록 수정했습니다.
- BUG-025 — 아사미의 중요 이벤트가 이전 임시값 때문에 발생하지 않는 문제: 「전학 온 이유」「도망가는 아사미」「알 리가 없어」「여기로 와」의 발생 판정이 실제 루트 실패 플래그를 읽도록 수정했습니다. 원래 날짜·진행 조건과 추첨 확률은 유지합니다.
- BUG-027 — COM 감독이 대타의 대좌투수○ 대신 안정감 능력을 읽는 문제: 대좌투수○의 올바른 능력 비트를 읽도록 수정했습니다.
- BUG-029 — 탈삼진 능력의 구속 보정이 다른 능력을 참조하는 문제: 2스트라이크 상황의 구속 보정이 탈삼진 능력을 확인하도록 수정했습니다.
- BUG-034 — 제2변화구의 제구·세로 변화량·COM 평가·오리지널 계수 오류 [일부 수정]: 누락된 제2 슬롯의 제구 보정, 제2 싱커와 SFF의 세로 상한 혼동, COM의 제2변화구 평가 누락, 오리지널 제2변화구의 스태미나·타격 파워 계수 참조를 수정했습니다. 커트볼 가로 변화량 제한은 수정하지 않았습니다.
- BUG-035 — COM이 최근 투구 이력을 읽을 때 구종과 슬롯을 혼동하는 문제: 최근 투구 이력에 올바른 슬롯 값을 저장하도록 수정했습니다.
- BUG-037 — 구피 모드 몰아치기(固め打ち) 취득의 타율 계산 오류 [일부 수정]: 3/6 같은 비율이 정수 나눗셈으로 0이 되던 처리를 수정했습니다. 양타의 방향별 취득 판정과 외야 위치별 이닝 집계는 수정하지 않았습니다.
